# Arquitetura do TaskForge

## Visão Geral

- Backend: Rails API-only
- Web: Angular SPA
- Mobile: React Native + Expo
- Auth: JWT
- Temas: Light / Dark / Mutant (pago)

## Tema Mutant (Pago)

Inspirado em Deadpool & Wolverine:
- Vermelho vivo (#E31C25)
- Preto profundo
- Amarelo dourado (#FFD700)

## Principais entidades

- User
- Board
- List (coluna do board)
- Card
- ChecklistItem
